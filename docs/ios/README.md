## Requisitos futuros de la app privada

- macOS con Xcode.
- Apple Developer personal team o cuenta válida.
- Provisioning y firma en dispositivo físico.
- Developer Mode cuando iOS lo exija.
- Explicación ATS para red local sin TLS, limitada al laboratorio.

Desde Linux solo se puede revisar código y diseñar contratos. No se afirma
compilación, instalación ni ejecución en iOS desde este entorno.
